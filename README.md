# 🏎️ ICRL - International Corgi Racing League 🏎️

Welcome to the **International Corgi Racing League** website - the most prestigious motorsport championship for corgis worldwide!

## 🐕 About

Where Short Legs Meet High Speed! This is a humorously serious F1-style racing league website featuring the fastest corgis on four paws.

## 🚀 Tech Stack

- **React** - UI framework
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling
- **React Router** - Navigation
- **Mock data.json** - No database required

## 📁 Project Structure

```
src/
├── components/
│   └── Navigation.jsx       # Main navigation bar
├── pages/
│   ├── Home.jsx            # Home page with featured racers and events
│   ├── Racers.jsx          # Grid of all corgi racers
│   ├── Events.jsx          # Race calendar and schedule
│   └── Rules.jsx           # Funny racing rules
├── data.json              # Mock data for racers, events, and rules
├── App.jsx                # Main app with routing
├── main.jsx               # Entry point
└── index.css              # Tailwind directives
```

## 🛠️ Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/vonam007/test_github_agent.git
cd test_github_agent
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
